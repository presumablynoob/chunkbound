================================================================================
CHUNKBOUND - BENEFICIAL STATUS EFFECTS
================================================================================

Every status effect in the pack whose registered MobEffectCategory is
BENEFICIAL, and what each one actually does.

89 beneficial effects, out of 152 registered in total.

How this was compiled:
  - The full registered effect list came from the ProbeJS registry dump
    (.probe/@special/types/index.d.ts).
  - Category (BENEFICIAL / NEUTRAL / HARMFUL) was read out of each effect
    class's constructor in the mod's own bytecode, not guessed from the name.
  - Behaviour text comes from each mod's in-game effect description. 60 of the
    70 modded effects shipped one. The remaining 10 had none, so their behaviour
    was read out of the implementing class and written into CBResources as
    proper in-game descriptions - these are marked [CBTweaks] below and now show
    in EMI like any other.

Note on "beneficial": this is the mod author's own classification. It controls
the HUD tint and whether milk-style cures treat it as good. A few entries below
are only loosely "good" - Kaleidoscope Cookery in particular registers all of
its effects as beneficial, including Hinder and Flatulence.

================================================================================
DESCRIPTIONS ADDED BY THIS PACK
================================================================================

10 effects shipped with no in-game description at all, so EMI showed only
"The effect appears to have no descriptions...". CBResources now supplies one
for each, via effect.<namespace>.<id>.description - the key emiffect reads:

  assets/artifacts/lang/en_us.json              magnetism
  assets/cobblemon/lang/en_us.json              cleanse_all, cleanse_negative,
                                                mental_restoration
  assets/kaleidoscope_cookery/lang/en_us.json   hinder, instant_smelting,
                                                projectile_dodge, vitality
  assets/relics/lang/en_us.json                 immortality, vanishing

Language files merge per key, so these add to each mod's own translations
without displacing anything.
