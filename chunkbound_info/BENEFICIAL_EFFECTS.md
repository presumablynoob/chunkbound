# Beneficial Status Effects

A reference for every **beneficial** status effect in Chunkbound, and what each
one actually does.

## Descriptions this pack added

Entries marked `+` above had **no in-game description at all**, so EMI showed
only *"The effect appears to have no descriptions..."*. CBResources now supplies
one for each, using `effect.<namespace>.<id>.description` — the key `emiffect`
reads.

| File in CBResources | Effects |
|---|---|
| `assets/artifacts/lang/en_us.json` | `magnetism` |
| `assets/cobblemon/lang/en_us.json` | `cleanse_all` · `cleanse_negative` · `mental_restoration` |
| `assets/kaleidoscope_cookery/lang/en_us.json` | `hinder` · `instant_smelting` · `projectile_dodge` · `vitality` |
| `assets/relics/lang/en_us.json` | `immortality` · `vanishing` |

Language files merge key by key, so these sit alongside each mod's own
translations without replacing anything.

## How this was compiled

- The registered effect list came from the ProbeJS dump
  (`.probe/@special/types/index.d.ts`).
- **Category was read from each effect class's constructor in the mod's own
  bytecode**, not inferred from the name. That matters — several mods mix
  beneficial, neutral and harmful effects in a single registry.
- Behaviour text is each mod's own in-game description where one exists
  (60 of 70 modded effects). The other 10 were read from their implementing
  class and written into CBResources as real descriptions.

**A caveat on "beneficial":** it's the mod author's classification, and it drives
the HUD tint and whether milk-style cures strip it. It is not a promise that an
effect is good for you.
